# Gestão Operacional — Tropical

Sistema de estoque, pedidos entre lojas, CMV e checklists.

- `index.html` — o sistema (telas)
- `sbdb.js` — conexão com o banco de dados (Supabase) e login
- `config.js` — endereço e chave pública do projeto no Supabase

Hospedado como site estático (Cloudflare Pages / Netlify). Cada alteração enviada
para este repositório é publicada automaticamente.

**Nunca** coloque neste repositório a chave `service_role` do Supabase nem arquivos
com dados de funcionários.
